# 🎯 Project Goals

| Goal | Target |
| ---- | ------ |
| Battery life | ≥ 2 h heavy use (LLM + analysis), ~3 h light use (coding / prototyping); unlimited when plugged in (pass-through) |
| Power input | **One** plug on the case charges and runs the deck at the same time |
| Weight | ≤ 3 kg, including the charger and IoT kit carried inside |
| Local LLM | Ready-made 3B–4B coding-agent model (tool calling), working as an agent fully offline — no training |
| Carry | Charger + IoT prototyping kit stored inside the case |
| Schedule | Built, tested and documented by **13 Dec 2026**, with a hardware paper draft |
| Budget | ~US$ 500 |
